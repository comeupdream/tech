What this does:
1. Subtle facial symmetry correction (only if needed, 10-15% max)
2. Strips all EXIF, IPTC, XMP & ICC metadata
3. Shifts color channels by a random 1-2%
4. Adds subtle pixel noise around the image edges
5. Scatters a few random interior pixels by ±1
6. Re-encodes as JPEG with randomized quality

The result looks identical to the human eye but produces a completely different file hash, perceptual hash, and metadata fingerprint. Face symmetry is only adjusted when asymmetry is detected — already-symmetric faces are left alone.
